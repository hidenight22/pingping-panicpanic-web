# PingPing PanicPanic

`소나 쏠래말래 쏠래말래 / PingPing PanicPanic` 공개 웹 플레이테스트 빌드입니다.

- 버전: `0.4.28`
- 용도: 모바일·브라우저 확대 맵 플레이테스트
- 확대 파일럿: STAGE 1 `1000×2100`, STAGE 4 `1400×2200`, STAGE 9 `1600×2400`
- 변경: 플레이어 추적 카메라가 실제 확대 월드에서 작동하며 코어·중계문·수호자·장애물·가변 통로를 확대 범위에 재배치했습니다.
- 테스트 접근: 메인 `GM` → 스테이지 `4` 또는 `9` 입력 → `선택 스테이지 개방` → `열린 해역 테스트`
- 현재 범위: STAGE 9 중계문 은닉·발견 규칙과 전체 100스테이지 확대는 아직 반영하지 않았습니다.
- 강제 광고 제거권 효과: 고정 배너와 자동 전면 광고 제거, 선택형 보상 광고 유지
- 웹 결제 주의: `검증용 결제 · 실제 결제 아님` 세션 모의 결제이며 새로고침하면 소유권이 초기화됩니다.
- 개발판 주의: GM 도구와 모의 광고가 포함되어 있으며 실제 광고·실결제·플랫폼 SDK가 연결된 출시 빌드가 아닙니다.
