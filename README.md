# PingPing PanicPanic

`소나 쏠래말래 쏠래말래 / PingPing PanicPanic` 공개 웹 플레이테스트 빌드입니다.

- 버전: `0.7.11`
- 주요 변경: 무저갱 현재·다음 구획 자산 선행 로딩, 라이벌 본체·중계문·투사체 대체 도형 노출 방지
- 시작 화면: 게임 제목·버전·로딩 진행도를 최소 1.5초 표시한 뒤 메인 화면으로 전환
- 허브: 하드·익스트림·무저갱이 모두 열린 짧은 모바일 화면에서도 장식·메뉴가 겹치지 않도록 대응
- 테스트 접근: 메인 `GM`에서 난이도·무저갱·외형을 개발용으로 개방 가능
- 강제 광고 제거권 효과: 고정 배너와 자동 전면 광고 제거, 선택형 보상 광고 유지
- 웹 결제 주의: `검증용 결제 · 실제 결제 아님` 세션 모의 결제이며 새로고침하면 소유권이 초기화됩니다.
- 개발판 주의: GM 도구와 모의 광고가 포함되어 있으며 실제 광고·실결제·플랫폼 SDK가 연결된 출시 빌드가 아닙니다.
