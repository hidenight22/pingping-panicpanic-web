# PingPing PanicPanic

`소나 쏠래말래 쏠래말래 / PingPing PanicPanic` 공개 웹 플레이테스트 빌드입니다.

- 버전: `0.4.30`
- 용도: 모바일·브라우저 확대 맵, 숨은 중계문 및 다중 발견 알림 플레이테스트
- 확대 파일럿: STAGE 16 `1400×2200`, STAGE 18·20 `1600×2400`
- 코어 발견: 플레이어 가시거리 또는 장애물에 막히지 않은 플레이어 소나가 처음 닿으면 화면 밖 코어도 발견 수와 함께 알립니다.
- 알림 스택: 최대 3개를 동시에 표시하고 이후 알림은 대기시켜, 코어·중계문 발견 로그가 수호자 발각 로그에 덮이지 않게 했습니다.
- 중계문 규칙: 세 파일럿에서는 시작 시 보이지 않으며, 플레이어 소나가 도달하거나 가까이 접근하면 해당 플레이 동안 계속 공개됩니다. 재시작하면 다시 숨겨집니다.
- 테스트 접근: 메인 `GM` → 스테이지 `20` 입력 → `선택 스테이지 개방` → `열린 해역 테스트` → STAGE `16`, `18`, `20`
- 확인 포인트: STAGE 16 시작 지점 일반 소나로 화면 밖 코어 발견 로그, 연속 알림 적층·퇴장, 숨은 중계문 발견
- 현재 범위: 전체 100스테이지 확대·숨김 적용 및 최종 밸런스 조정은 아직 반영하지 않았습니다.
- 강제 광고 제거권 효과: 고정 배너와 자동 전면 광고 제거, 선택형 보상 광고 유지
- 웹 결제 주의: `검증용 결제 · 실제 결제 아님` 세션 모의 결제이며 새로고침하면 소유권이 초기화됩니다.
- 개발판 주의: GM 도구와 모의 광고가 포함되어 있으며 실제 광고·실결제·플랫폼 SDK가 연결된 출시 빌드가 아닙니다.
